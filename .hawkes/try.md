1. Open the beta demo site and find the Recipes link; open `recipes.html`.
2. You should see four recipes: chat, cursors, shared state, a room with a password. Each shows its code.
3. Press the live link on a recipe and open it in a second tab on the same room. Send a message, move the pointer, add a point: the other tab sees it.
4. In the password recipe, try a different password in the second tab: it should not meet the first.
