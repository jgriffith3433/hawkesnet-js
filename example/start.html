Hawkes Net: getting started

Five steps from installing the SDK to two browser tabs talking and sharing cursors in one room, with what you should see after each step. The step code is the exact tested file example/start.mjs.

1. Install 2. Lobby & status 3. Joins & leaves 4. Chat & cursors 5. Two tabs in one room
  1. 1

    1. Install from the GitHub tag tarball

    Games depend on a tagged release tarball from GitHub (or npm install @hawkesgen/net). Zero dependencies. In a plain HTML page without a bundler, you can also import the same exports from https://net.hawkesgen.ai/sdk/hawkes-net@1.mjs.

    npm install "https://github.com/jgriffith3433/hawkesnet-js/archive/refs/tags/v1.4.0.tar.gz"
    What you should see: package.json records the tag tarball and npm finishes with zero extra packages
    added 1 package in 1s "@hawkesgen/net": "https://github.com/jgriffith3433/hawkesnet-js/archive/refs/tags/v1.4.0.tar.gz"
  2. 2

    2. Create a lobby on the free test project

    Start start.mjs (or a <script type="module"> in your page). netdemo is Hawkes Net's free test project; swap in your own project id from net.hawkesgen.ai when you make one.

    import { lobby } from '@hawkesgen/net';

const net = lobby({ project: 'netdemo', name: 'Ada' }); // netdemo is the free test project
net.when('status', ({ status }) => console.log('status:', status));
    What you should see: your console logs each connection transition as the room connects
    status: connecting status: online
  3. 3

    3. Log when another player joins or leaves

    peer:join passes the arriving peer ({ id, name }); peer:leave passes { peer, reason } when their tab closes or leaves.

    net.when('peer:join', (peer) => console.log(`${peer.name} joined`));
net.when('peer:leave', ({ peer }) => console.log(`${peer.name} left`));
    What you should see: opening a second tab (and closing it) logs the peer in your first tab
    Bob joined Bob left
  4. 4

    4. Listen for chat messages and cursor poses

    net.on('chat', ...) delivers reliable messages once and in order. net.onPose(...) receives each peer's latest [x, y, z] coordinates (from 0 to 1 across the window).

    net.on('chat', (text, from) => console.log(`${from.name}: ${text}`));
net.onPose((id, state) => {
  const who = net.peers.get(id)?.name ?? id;
  console.log(`${who} is at ${state.p[0].toFixed(2)}, ${state.p[1].toFixed(2)}`);
});
    What you should see: messages and pointer moves from the other tab print as they arrive
    Bob: hello Ada Bob is at 0.60, 0.40
  5. 5

    5. Join the room and open two tabs

    Send a greeting when status reaches 'online', broadcast your pointer on pointermove, and call net.join('getting-started'). Open your page in two tabs — or press Run it here below in two tabs of this page.

    let greeted = false;
net.when('status', ({ status }) => {
  if (status === 'online' && !greeted) { greeted = true; console.log('you: hi, anyone here?'); net.send('chat', 'hi, anyone here?'); }
});
if (typeof addEventListener === 'function') {
  addEventListener('pointermove', (e) => net.pose([e.clientX / innerWidth, e.clientY / innerHeight, 0]));
}
net.join('getting-started');
    Open the playable demo
    What you should see: two tabs in room getting-started seeing each other's greeting and cursor
    Tab 1 · getting-started● Connected
    Ada (you) Bob · 0.60, 0.40
    Tab 2 · getting-started● Connected
    Bob (you) Ada · 0.35, 0.50
    status: connecting status: online you: hi, anyone here? Bob joined Bob: hello Ada Bob is at 0.60, 0.40
